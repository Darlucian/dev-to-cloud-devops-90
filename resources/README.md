# Resources

What helped me learn, with a short note on why.

## Roadmap
- [roadmap.sh/devops](https://roadmap.sh/devops): visual checklist of the whole field.

## Linux
- [Linux Journey](https://linuxjourney.com): gentle, beginner-friendly lessons.
- [The Linux Command Line](https://linuxcommand.org): free book.
- [OverTheWire: Bandit](https://overthewire.org/wargames/bandit): a game to practice the command line.

## Git and Python
- [Pro Git](https://git-scm.com/book): free book.
- [Learn Git Branching](https://learngitbranching.js.org): interactive and visual.
- [Automate the Boring Stuff with Python](https://automatetheboringstuff.com): free online.

## Docker
- [Docker: Get started](https://docs.docker.com/get-started): official docs.
- [Trivy](https://trivy.dev): image vulnerability scanner.

## AWS
- [AWS Skill Builder](https://skillbuilder.aws): free digital courses.
- [AWS Workshops](https://workshops.aws): free hands-on labs.
- [Well-Architected Framework](https://aws.amazon.com/architecture/well-architected)

## Terraform and CI/CD
- [HashiCorp Terraform tutorials](https://developer.hashicorp.com/terraform/tutorials)
- [GitHub Actions docs](https://docs.github.com/actions)

## Kubernetes and monitoring
- [Kubernetes tutorials](https://kubernetes.io/docs/tutorials)
- [kind](https://kind.sigs.k8s.io): local clusters.
- [Prometheus docs](https://prometheus.io/docs)
- [Google SRE Book](https://sre.google/books)
