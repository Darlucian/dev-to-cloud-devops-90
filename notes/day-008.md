# Day 8/90: Linux fundamentals

**Date:** 2026-11-16 · **Class day:** no

## Problem
I needed to get comfortable working with Linux commands and file management, since Linux is an essential skill in Cloud and DevOps engineering.

## Solution
I started with the **shell**, a program that lets us interact with the operating system by typing commands, and then practised in hands-on labs: creating files, navigating directories and manipulating files.

Commands and tools I explored:

| Command | What it does |
|---|---|
| `bash` | The shell program I used to run commands |
| `pwd` | Prints the folder I'm currently in |
| `mkdir` | Creates a new directory |
| `touch` | Creates an empty file |
| `file` | Tells me what type a file is |

```bash
pwd
mkdir practice
touch notes.txt
file notes.txt
```

## Lesson
- Working with commands wasn't entirely new to me, because of my background in PHP, JavaScript and Node.js.
- Learning a command is not enough. Practising it in labs is what makes it stick.
- I'm beginning to understand why Linux is such an essential skill in Cloud and DevOps engineering.
