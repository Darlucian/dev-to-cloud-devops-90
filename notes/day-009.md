## Key concepts (in plain English)
- **UID / GID:** Linux identifies users and groups by numbers. The UID is a user's ID number and the GID is a group's ID number.
- **Permissions:** every file has read, write and execute permissions for three sets of people: the owner, the group, and everyone else.
- **Ownership:** every file belongs to one user and one group, and that decides which permissions apply to whom.
- **`sudo`:** lets an allowed user run a command with administrator (root) privileges. What each user may do is set by configured policies.

## Related commands to practise
| Command | What it does |
|---|---|
| `id` | Shows a user's UID, GID and groups |
| `groups` | Lists the groups a user belongs to |
| `groupadd` | Creates a group |
| `usermod -aG` | Adds a user to a group |
| `ls -l` | Shows permissions and owners |
| `chmod` | Changes permissions |
| `chown` | Changes owner or group |
| `sudo` | Runs a command as an administrator |
