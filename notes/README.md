# Daily notes

One file per day, named `day-001.md`, `day-002.md`, and so on. Copy [_TEMPLATE-daily.md](_TEMPLATE-daily.md) to start a new one.

Day numbers follow the calendar (Day 1 = Mon, Nov 9, 2026), not the number of posts. If I miss a day, I say so and keep going.

**Before committing a note or screenshot:** check for keys, tokens, `.env` contents, AWS account IDs, and public IPs.
