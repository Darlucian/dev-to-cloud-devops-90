I also explored Linux user management and learned to interpret information from system files:

- `/etc/shadow`: stores password-related account information
- `/etc/group`: contains local group information

## Key concepts (in plain English)
- **`touch`:** creates an empty file (or updates the timestamp of an existing one).
- **`nano`:** a simple text editor that runs inside the terminal. To save, press `Ctrl+O` then `Enter`. To exit, press `Ctrl+X`.
- **`/etc/group`:** a plain text file listing each group, its group ID (GID) and its members.
- **`/etc/shadow`:** stores account password information, in scrambled (hashed) form, not the real passwords. It's protected, and normally only the administrator (root) can read it, which is why `sudo` is needed to view it.

## Related commands to practise
| Command | What it does |
|---|---|
| `cat /etc/group` | Shows the list of groups |
| `sudo cat /etc/shadow` | Shows the shadow file (needs `sudo`) |
| `cat myfile.txt` | Prints a file's contents |
